# Territorial Urban Metabolism — results across scales (ECLECTIC)

This work is part of **[ECLECTIC – Enabling circular economy action plans for small and medium-sized cities](https://www.eurac.edu/en/projects/eclectic)**, a Driving Urban Transitions (DUT) Partnership project funded by Formas, FCT, LMT and MUR and co-funded by the European Union.

The findings are a **draft** under review. Data: Statistics Sweden (SCB), Trafikanalys, ISTAT, Statistics Portugal (INE) and Eurostat. Results are model estimates.
